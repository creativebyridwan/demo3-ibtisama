# Demo 3 — Ibtisama (ابتسامة)

Demo website klinik gigi keluarga (Arab, RTL) di Zliten, Libya.
12 halaman: Beranda, Tentang, Layanan, Detail Layanan, Dokter, Profil Dokter,
Galeri Senyum, Harga, Blog, Detail Artikel, Booking (+login simulasi), Kontak.

Palet: Espresso #351904, Ember #8B3A00, Gold #E08E00, Malibu #FFECB8.
Font: Alexandria (judul) + Readex Pro (isi). Reveal 900ms (atas/kanan/kiri).

Semua nama, harga, angka, dan foto adalah contoh demo.
